## Negative values

Home Credit reports several `DAYS_*` features as days *before the application date*, so negative values are expected and are NOT treated as sentinels. We do not invent `__was_<neg>` indicators for arbitrary negative values. The only documented special numeric value in this table is `DAYS_EMPLOYED == 365243`.

## Implications for downstream phases

1. **Phase 2 — preprocessing must handle 16 categorical columns** including high-cardinality `ORGANIZATION_TYPE` and `OCCUPATION_TYPE`. The HELOC pipeline assumed numeric-only data; we generalize without breaking HELOC.
2. **Phase 4 — sentinel-aware ablation is justified** for `DAYS_EMPLOYED == 365243`. We add a single indicator `DAYS_EMPLOYED__was_special` and replace the special value with NaN. We do NOT add indicators for other negative values.
3. **Phase 5 — permutation-importance stability** is expensive on 100+ numeric columns. We will evaluate on a fixed deterministic subsample of the test set with a small configurable `n_repeats`, kept identical across models and seeds.
